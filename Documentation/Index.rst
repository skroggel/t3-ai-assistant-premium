====================
AI Assistant Premium
====================

:Extension key:
    ``ai_assistant_premium``

:Package name:
    ``madj2k/t3-ai-assistant-premium``

:Namespace:
    ``Madj2k\\AiAssistantPremium``

:License:
    GPL-3.0-or-later

:TYPO3:
    TYPO3 v13.4 LTS

:PHP:
    PHP 8.4 or newer

AI Assistant Premium extends `AI Assistant for TYPO3
<https://github.com/skroggel/t3-ai-assistant>`__ with commercial integrations
for PDF indexing, external Shopware product indexing and AI-enhanced search
result workflows.

The premium extension deliberately builds on the data model, indexing framework,
assistant profiles, pipelines, vector-store integration and frontend chat
functionality of the base extension. Install and configure the base extension
first; this manual documents only the additional premium functionality.

..  note::
    Premium functionality requires a valid license key. The extension verifies
    the key against the static license endpoint at ``license.mediafiles.de``.
    See :ref:`premium-license`.
