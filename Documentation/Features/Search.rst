AI-enhanced search
==================

The Premium search integration enhances an existing search engine. It supports
two frontend integration styles:

* :ref:`premium-classical-search` for a native search form and rendered result
  list with the compiled Vue bundle;
* :ref:`premium-vue-search` for a Vue-based search application using the
  page-level Premium JSON clients.

Both styles use the same Assistant profiles, Orchestrator, JSON controller,
signed frontend tokens and result validation.
